## AI ASSISTANT
### AI PRINCIPLES
Wolftech is dedicated to harnessing Generative AI to enhance its public mission and deliver exceptional value to audiences. The company is committed to addressing challenges posed by Generative AI in the media industry, such as maintaining trust, protecting copyrights, and facilitating content discovery.
To check our AI principles visit our site: https://wolftech.no/ai-principles-at-wolftech/
### AI MODELS SUPPORT
We currently support both Azure and Open AI as model providers for the Scout Assistant and Inspire (license for the integration required). For OpenAI integration an OpenAI API key is required, all available OpenAI models are then listed in admin view, where admin users can also assign which models should be used for which tasks. Azure allows the connection to hosted models, requires a model link, model name and API key.
### EDITORIAL AI ASSISTANT
It allows the user to use AI to analyze a piece of text or article added in a story. It helps create content out of given text that can be used as a suggestion by the user.
This can be triggered from the background information segment:
Current options include:
Bullet point summarisation
Summarize (with chosen max characters)
Social Media Post (to reformat the text for different platforms specs)
Rewrite for video script (for a chosen platform)
Blog Post
Translate to
Writing Feedback
Generate title Suggestions
Rewrite in the tone of
Rewrite for target audience
Keyword Research for article (Generate keywords)
Custom Prompts (For conversational results)
### SMART PUBLISHING
The Assistant is also available when importing content from the story into a publishing point to enable quick transformation of content into multiple formats.
Use cases include
Formatting for social media platforms
Localisation into another language
Personalisation of a target audience group
When you import content from the editor you will now see the Smat Pub Point option:
When this is loaded you will again be able to choose from a range of prompts and hit create.
After that you can import the result to the Pub Point from where you can continue to edit it before publishing so the human is always in the loop and in control.
### INSPIRE
