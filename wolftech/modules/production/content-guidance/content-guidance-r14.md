## GUIDANCE
### GUIDANCE REQUEST
Your admin may have set a number of guidance workflows so that certain supporting teams such as legal, rights & clearances, risks or music supervision can assist you throughout your story lifecycle.
Guidance can be requested both on a background information text segment and/or on a publishing point.
In background information guidance can help you with the development and production process:
Guidance on Publishing points is useful for checking elements before publication once you know your target distribution.
In both of them you will need to select all guidance types required and when (date and time) you need to get an answer by with some notes
The pop up window allows you to do multiple request for different types of guidance at once and then can be tracked in the request panel:
.
Note, if you see a multiuser icon next to the resource type is because this information will be shared across all guidance teams you request guidance from
### GUIDANCE COMMUNICATIONS
The guidance message function allows you to interact with the relevant team.
Do note that for system where notify all is enabled in admin all conversations are shared across all guidance requests
##### Initial Guidance Request
When guidance is first requested we send a notification
This alerts everyone who is supposed to be alerted for new guidance requests, which includes:
The person directly assigned in the guidance modal (if anyone is direct booked)
If the guidance section is configured to alert all resources in the requested type, everyone in that type will also receive a notification
Note: If the person making the request is in the notify group, they will not receive a notification unless they deliberately directly book themselves.
The alert takes you directly to the guidance section in question. All resources being notified will receive this same message. If you direct book someone they will get a booking added to their calendar, but still they will only get the one notification. You can direct book someone outside the resource type.
##### Alternate request workflow
If you are requesting a guidance resource type that is not set to notify all resources, it is recommended that you directly book someone. If you do not, a booking request will be generated, and will need to be assigned to a resource by a booker. The resource will then receive a “you have been booked” message.
##### Guidance Responses
Once guidance has been requested, any responses to the guidance section will generate an alert to all people in the initial notify list, plus the person who requested the guidance (and anyone else who decides to manually “subscribe” to the guidance section)
Note: The person doing the action will not receive a notification (as that would just be annoying during normal use of the application).
##### Guidance Log
Each guidance creates a complete log to track the interaction that led to the approval or rejection.
