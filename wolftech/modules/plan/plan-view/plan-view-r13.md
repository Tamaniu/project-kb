## PLAN


The Plan module is at the heart of Wolftech’s story planning. It is the town hall where teams get full visibility of all the activity happening today, this week or this month across their part of the organization. It can track internal events, external calendars, pitches, stories, productions, tasks, or publishing points filterable in every way you can think of.


In this guide we will help you to get to know its functionality deeply so you can make the most of it and are confident in setting them up if you are an admin.

Note: This guide is based only on the “new plan view.” There are significant differences with the old plan view which will not be covered in this guide. The old plan view will no longer be available from R14 onwards, and we have chosen to focus the documentation on the new one.

##### Filters

Now that you know how to set up views let us go into more detail about the different columns and filter options available. At the top are the column types that define the items you may want to display in a column. Do note you cannot mismatch column types into one column but need to choose one per column.

Within the Stories filter it is, however, possible to combine stories and timeless stories in one column. To do so simply choose the story filter and select the different content types


Over on the left side of the window you will see your filter options:


Departments, allows you to filter your items by the department(s) related to it (whether it was created in that department or shared with it. The Home department checkbox is a shortcut to it.

Note that when selecting departments, selecting a top category department will not automatically select the departments under it because sometimes content is created at multiple levels.

To select all sub-departments, click on all, or none buttons that display on hover next to them.

All selected departments will display below allowing you to remove one of them easily too.


Offices, allows you to filter your items by the office(s) related to it (whether it was created in that office or shared with it. All selected offices will display on the right allowing you to remove one of them easily too.


Genres, can help you organize editorial work around certain genres across multiple departments


Production Type filters can help you preview stories across multiple coverages (Dayside, overnight, breaking, etc. or diverse types of content like short form video, tv ½ hs, Social, etc.)


Content Types, allows you to narrow each column to display top stories vs other stories or pitches, timeless, discarded, etc.


Content Statuses: this is a perfect way to have different columns with different statuses to track the progress of work.


Groups can be an effective way to have dedicated columns for each group. Groups can be used in many ways but allow you to mismatch stories from multiple departments or genres or offices around a common custom group. This could be for an event, like the Olympics, or it can be groups defining aspects not found previously, like high-risk stories where your security and risks team is tracking them by risk level.


Order: Finally ordering allows you to categorize the information within one column in diverse ways.

You can order it from the organization. So, if you have selected multiple departments, you will have a sub section for each department.

You can order it by content type, so you see sections for top story, other story, pitches or discarded

Or you can order it by office, genre, production type, group, or none (in case you rather not show any categorizations).


Time zone Indicator in Plan view

An admin switch allows users to control the visibility of the time zone indicator. When the switch is on, the indicator will be hidden if the local and folder time zones match. When off, the indicator will be shown even if the time zones match. These enhancements will provide greater clarity and flexibility in managing Publishing Points in Plan View.

### USE CASES


It can be useful to look at a few examples of Plan views to understand how you can lay out the information as well as how some of the actions playout in real life.


##### All Departments (Newsgathering)

A classic example is where you set up a view with each column representing a department or sub-department with no other filters applied and ordering by content type:


This view allows you to see all the stories created from the different departments at a given time and break silos providing access to all the newsgathering for each story in a powerful view. By dragging items around you can also:

- Share a story with another department for collaboration

- Copy a story to another department to expand the coverage with another angle

- Move a story to another department that may be better suited to cover it.

- Change a story into a top story to prioritize it

- All while using the eye icon filter to check where everyone is deployed to on the day


##### Office Overview with Events Tracking (Local Focus)

Sometimes it may be helpful to get a full overview of what a specific office or region is covering and the events happening within that region. This would include columns with filters by active departments in the region but with an added filter for the specific office in each of them and ordering them by content types.

With a split view, you can set some further columns for calendars by adding a filter for the office to display the events at the bottom.

Now you can easily see both stories and events in the location and by dragging an event to a department column you can quickly create stories out of events.


##### Department Progress Views (Production)

This view is especially useful to track the progress of the team's work.


Here you would lay each status with the same selection of department(s) but add a different status filter to each column and order it by content type.


Here you can have a column for pitches, a column for discarded stories and columns with different status to see the progress of stories at various stages.


In this view it can be immensely powerful to use the search bar to track the work of each team member, where you can see in which status the pitches or stories are at for a given colleague.


With the drag action you can quickly update the status of a story or pitch in a review session.


Being able to view who is assigned to each story on that given date can also be helpful to plan the day with your team.


##### Publishing (Offers and Orders)

With a publishing view you can lay all your platforms so editorial leads can take up offers to use the stories in their shows and platforms effectively ordering packages from the offered stories (available for the day) on the left panel


##### 24/7 News Channel

Here, the concept is that you want to track all the stories published to a set of rundowns covering a 24/7 news channel where each column displays a specific publishing status.

As you create publishing points for those rundowns you can track the status of those publishing points thus providing a fantastic way to have an overview of your channel´s editorial output.

By dragging stories or episodes from the left menu you can create new publishing points, and it will ask you on which rundown slot (each being a publishing folder) you would like to schedule it in.

If you set each folder to have a start time it will automatically set the start time to your rundown start time.

If you set the rundown to track total run time it will display the total run time of the combined publishing points as you add multiple ones to it.

Finally, by dragging the publishing point across columns you can easily change their status.


##### Rundowns Block Partitions

A variation of this format is where you may want to create folders for each rundown part or block:

With this publishing column format you could have one publishing folder be your Floated Stories or Unassigned Stories that are not tracking TRT (Note this is not truly floating stories in iNews or other rundown apps yet but mimicking the concept so you can have stories available to the rundown that have not been assigned yet to a block).


Each block represents a publishing folder under the Show's Hierarchical folder. So long as all of the publishing folders have been created from the same sub platform you should be able to easily share stories across different days of this rundown.


##### Long Form Postproduction Tasks Overview


In this example you create a dashboard where you can track a task type per column for several tasks managed by a service department (like an ingest team in post-production).

Each column is not filtering departments as they centralize the resources and can handle ingests for any department. However, you want to filter for a stage type. In this case we have a column for media - ingest, another one for transcription, translation, online edit, etc.

With this overview you get to see the active tasks on those dates, and which productions they belong to. the status of the task and the assignee. With an easy approach to opening those tasks.


You can also expand one of the columns to quickly get to see all tasks for that task type over the week.
