## GREENLIGHT


### GREENLIGHT

##### Intro

Greenlighting a story or production is sometimes required and can be done by a subset of people with those correct permissions. The process of greenlight can be as simple or involved as admins decide to make it.

The greenlight process can have technical and organizational operational checks not defined in the system.

The production greenlight process is more involved than the story greenlight process.

Let us look at the options.

##### Operational Greenlight Checks

Beyond the content categorization where you can define which elements are required before greenlight including genres, formats, descriptions, the correct department level, or additional information, optionally you may enforce other checks like:

- Adding at least one publishing point to know where you plan to publish the content

- Going through a budget check

- Adding a budget code

- Deciding on which optional stages are required for the production

- Reviewing the timeline

- Creating the Story-Production MAM collection

Once you are happy with the project readiness if you have the permissions, you will be able to greenlight it

##### Greenlight notification and Summary

Once you click on the greenlight button it will mark the project as greenlit and will notify all booked resources and defined greenlight contacts for the department that the production is now greenlit.

It will also send a greenlight summary email to all people booked on it. (Note this is currently disabled as we are fixing the formatting of it.)

### ADMIN

##### Deciding on Greenlight Workflows

You may choose to have greenlight workflows in your system or not at all. Please contact your system administrator to set this up with the Database support team.


Note: Once Greenlight workflows are enabled in the system these will apply both for stories and for productions. Today it is not possible to have greenlight workflows differ between these 2.

##### MAM Collection Creation

You may decide that the story collection should be auto generated on greenlight, so you can enforce basic metadata before creating identities in the MAM

To do so go to the advanced section in admin

Many people prefer to keep this flexible, but it is an option for some clients.

Here you will soon see another option to Allow users to create MAM folder before greenlighting


##### Additional Checks

Other granular requirements like having to add a publishing point before greenlighting is done with customization support. Contact the wolftech team if needed.


##### Greenlight Notifications and summary


In the admin notifications settings, you will be able to define which options for the users will have for this type of notification and whether they can unsubscribe to them. Typical greenlight emails are enforced at admin level to make sure everyone is on the same page on project start.


For each department, you can also set users that should receive notification of greenlight even though they are not directly booked on the story or production. This is useful for execs that are just overseeing a lot of content and may not be booked on the projects
