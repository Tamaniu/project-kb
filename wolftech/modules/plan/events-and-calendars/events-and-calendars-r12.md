## EVENTS AND CALENDARS

### INTRO
Events are items happening in the future where you don´t know if you will create a story out of it but are worthy of recording for future reference.
We have 2 types of events in Wolftech
- Those generated internally (Internal Events)
- Those that we ingest automatically from 3rd party systems (External Events).
#### Int. vs Ext. Events
External events are like external feeds, they cannot host bookings, conversations or any further work. You can however create internal events or stories out of them, which will be listed in their card afterwards, as well as pin them:
Internal events on the contrary have pretty much all of the functionality from a story so all information can be planned ahead and if you decide to create a story out of them all information will be transferred.
The main difference between events and stories is that you cannot create publishing points out of events. All publishing comes from stories.
#### Calendars
###### Set up
Events, whether internal or external are grouped in calendars.
Internal calendars are defined by the admins.
External events are grouped by the 3rd party system and defined in the workflow engine.

To create a new internal calendar admins can go to the Admin - Calendar Types section where you can click on the 3 dot menu to create a new one

Once created you can assign them a color to clearly identify events belonging to this calendar.
Be careful because old calendars may inherit a color from the old color system and it is imperative that you apply a color in the new system to make it visible in the event card.

###### Permissions
Here in this section admins can also manage who gets access to the events. By default all users will be added (WtnAll), however this can be restricted to any user groups (whether custom, department user groups or authorisation groups)

### QUICK ADD AND CATEGORISATION

###### Quick Add

To create an event the easiest way is to go to the Quick Add (orange plus icon button) and select Event. This can be done from the web or from the Wolftech Go app
Here you will be able to name the event, give it a description, categorize it with a genre, select the calendar it belongs to and give it some dates and times.

###### Find Similar Events

As you type in the title and description of your event it will display any existing events where the title or description have matches to avoid duplication

###### Setting a Genre
Just like with stories you can assign a Genre to an event. This allows people to filter searches for events with specific genres. It will also default stories created out of this event to be tagged with the corresponding genre.

###### Choosing a Calendar
In the quick add module you will be able to set in which calendar you want to host this event. Be mindful that depending on which calendar you add it to different set of users will get access to it.

###### Default Calendar Type

Note that you can define your default Calendar Type in the My Page profile menu so you don't need to select it each time:

###### Time options
In the quick add you will be able to choose from
- Specifying times (to give it both a start and an end time)
- No time (All Day by default)
- Start time only (gives it a start time and assumes a 23:59 end time although it does not display it)
- End time only (gives it an end time and assumes a 00:00 start time although it does not display it)

###### Date Options
Now you can give your event a date. This will default to today´s date for speed but here you can set a future date and even a date range.
By opening the date picker you can easily click on a start and end date to set the range

###### Timezone options
Once a “time option” and a date have been added you will be able to define the times and the timezone for the event.
This will help international colleagues to understand exactly where and when the event is truly happening in relation to their timezone.
Here you will be able to choose a recent time zone, search for one time zone with the reduced, more practical list of time zones, or expand to see the full list of time zones for more granularity.

Overall we are using the UTC convention for best results.

Do Note: Events without a time will display only the date of the event rather than try to adjust it to a new timezone
###### Office
On top of the previous Calendar grouping, Genre, title, description and date-times, in the full page experience you will be able to tag the event with office(s) so you can further filter and group events. Again you can search for your office to quickly find it.

###### Production Types-Addl Info
If you have enabled Production Types (Coverage) in your system, you will also be able to give an event a production type, this will trigger the creation of additional information custom fields in the event.
Note all of the information that you apply to the event will automatically be made available to any story created out of the event which is fantastic for forward planning.

###### Status
Events have 2 statuses that can be applied
- Active
- Discarded

### EDITORIAL
All of the same functionality as per stories and pitches and episodes is available to events when it comes to using the background information editorial section to add segments of text. Please refer to the editorial guide for further details.
All newsgathering and information will make its way to the stories created out of the event.

### GUIDANCE
Guidance requests can be triggered within editorial segments inside of events just like in stories.
See the Guidance guide for more information.
#### Tracking
Just like with stories in the tracking section you will be able to see any stories, pitches, events or logs that have been created out of the event.
To create stories or pitches out of the event simply drag it to a plan view column or choose the 3 dot menu and select the type of item you need.

### HUNTER SEARCH
Events come with a hunter panel on the right side so you can search for items in the system and across your connected MAMs. It is easy to link items to your event with drag and drop actions like you are used to in stories.

### COMMUNICATION
###### Chat
You have a fully featured event message thread. All features apply, refer to our communication guide.
Bookings chat and editorial segments chats will work just the same way.
###### Alerts
You can send alerts from an event. Please refer to our communication guide for further details.
###### Activity Log and Follow
Editorial changes to the event will be tracked in the activity log, you can follow an event just like stories and those will be displayed in the activity feed and in notifications if enabled. For a more detailed guide please refer to our communications guide.

### MEDIA WORKFLOWS
The Live Media, Media Storage and Footage panels work the same way as stories. Please refer to the Media Workflows guide for further info.
Do note that the media collection created for an event will be separate from that of the story created out of it. All embedded experiences continue to be supported:
Elements added to the board in the event will actually make their way to the stories at the time of story creation. Ie. elements added to the event after the story is created will not automatically sync to that story. They will only make their way to new stories created out of it.

### LOCATION AND MAPS
Events can have location(s), just like stories. Great for adding where the event will take place.
Here you can add further detail, drawings, points of interests etc. Please refer to the location guide for more information.

### RESOURCING AND FINANCE

You can manage bookings inside of an event. This can be helpful in multiple ways as you may have an events team managing the logistics or you may want to plan who is going to cover the event before assigning them the creation of multiple stories as part of the event.

Bookings work just the same as stories, with location and risk assessment workflows included. Please refer to our resourcing guide for more details.
Worth noting that when you create stories out of the event you will be asked whether you want to link the bookings from the event into the story.
This will allow you to display the existing bookings from the event in the story without copying or duplicating existing bookings for a clean record.

If you have the Finance module enabled, and have the correct permissions to access it, all cost tracking expected from those bookings will be tracked in the finance section. Please see the resourcing guide for more information on this panel.

### PLAN VIEW AND LEFT MENU
###### Overview
The left menu is a quick access view of elements on a given day. Each element gets a column (one for stories, one for events, one for external events, publishing points, etc.) Here you can filter what you personally would like to see.
Below you can see the difference of internal events vs external events in the left menu
As you can see, internal events get more information from the item itself, including the color of the calendar, a sidebar with the colors of the departments that have created stories out of them, times, locations and more.
In contrast, external events provide the basic information shared by the 3rd party system. This includes title, description, Event date time and last updated date time. We can also display if stories were created out of them the department colors on the side bar.
The plan view hosts dashboards that can display any combination of elements from the system grouped into views that are then shared as collections of views. Views can also be private rather than shared and can be marked as favorite with the star icon..
Below you can see a view called Demo Event View with a column combining a number of internal calendars and another one with an external calendar.
Filters
The filters that are used to create both the left menu and the plan view are the same and the results will be the same when applied on either of those sections.

For internal events
You can
- filter events by Office(s), Genre(s) or the Calendar(s) they belong to.
- Group them by calendar, genre, office or none (which will show them all without grouping).
- Determine if you would like to hide any empty groups (not containing matching results).
- Display only events that I have created or I ´m booked in (My content)
- Specify the width of the e column you are setting up in the plan view.
- Choose to included events that are discarded

In the case of discarded events they will be shown alongside active events but will have a clear discarded icon.

For External Events
You can
- Choose the external calendars to include in the column
- Filter them by the external calendar categories
- Filter them by the subjects of the external events
- Options to Hide Empty groups
- Define the width of the colum
- Do note My Content does not really apply here
###### Sorting
Events whether internal or external, in the Left menu or Plan view, are always sorted chronologically.
- All Day events (that do not specify time) are interpreted to start at 00:00 hs and ending at 23.59 hs
- Start time only event are interpreted to start at specified time and end at 23.59 hs
- End time only events are interpreted to start at 00:00 hs and end at the specified time.

###### Display Options
In the Plan view and on the left menu you will have options to display more or less information on the event cards.
For internal events please see the diagram below to understand how these correlate to the card information
- Location time is the time specified for each location
- Event Time is the actual time specified for the overall event
- Images will come from the main image in the board
- Extended title is possible if your title is longer than what fits in the card
- Description will show up to 256 characters
- Full Description will show the description in its entirety
- Guests and Staff bookings can be displayed
- They can also be filtered to only show the bookings matching the dates in the plan or left menu
- Publishing time does not apply to Bookings
- Notes does not apply to Bookings

For external Events
- Choose to show description vs full description or both

###### Actions
From the left menu or from one plan view column to another column you will be able to drag events from a calendar column into a story column to create a story out of an internal event or an external event.
