## RESOURCING: BOOKINGS


Resourcing is a major part of the Wolftech application allowing you have clarity on who is doing what when as well as driving better collaboration across teams.


### STORY BOOKINGS


##### Story Booking Page

In the second tab of the story, you will find the area for bookings

Here you can see Booking grouped under

- Bookings for the story

- Bookings associated with a particular location (Note, you may need a location risk assessment in place to confirm them)

- Bookings for a particular publishing point


On the right you will be able to search for resources and book them.


##### Adding Contacts

This action will load the list of guests (contacts) on the right to choose from. When you click add it will add a contact card as reference to the story. Note this is not a booking per se but adding the profile to the story so you know that contact is associated with the story but is not booked on a given day or time.


Note this does not add a reference of the story to the profile booking history as it is not a booking.

##### Bookings

Here you will be able to book people or equipment for the story. It will load your resources on the right from where you can book guests (contacts), employees, freelancers, vendors, or equipment.


####### Finding the right resource


- Use the side buttons on the right to choose categories (Staff for employees and freelancers, technical for equipment, teams, or guests)

- Use the search bar to find someone in particular

- Leverage the filters to refine your search by resource type, office and more

- Use your recently used resources

- Or navigate through the resource types of sections


Finally, if you do not find the resource you may want to create a profile for the freelancer or guest that is not listed, and you can do so via the + button below.


####### Booking Request Modal

When you click add you will be presented with the booking request modal where information about the booking can be entered.

To the right you will see the resource´s calendar for the day to check for clashes and availability.


On the left you will see the booking form.

Depending on the resource type you may have to enter certain mandatory fields set up by your admin.

- The title will be displayed clearly for the assignee, so it is important to fill in.

- Location is important when grouping resources around a location. If you try to add a new one, it will default to the location of the resource you are trying to book but can be overridden.

- The office will use the office of the story.


There are ways of blocking time for a booking:


- All day bookings are tasks that need to happen on a day but that do not block anyone from a specific time to another time and do not display as clashes in the booking page.

- “Book to shift” books people to the full shift defined in the system for that person on that day.

- Setting start and end times allows for more precision


Do note a booking may span multiple days.


- The notes field allows you to expand on the requirements.


####### Confirmation levels


You can “Book” or “Book and Confirm” or “Ask to Confirm”


- If you book it will create an in-progress booking (awaiting confirmation) you are planning for it but cannot confirm it yet

- If you book and confirm it will confirm the booking and notify the resource that they have been booked.

- Finally, you can ask the resource to confirm they can do the job. This is particularly useful with crews on a location that may or may not be able to take care of a job.

The booking confirmation request sends push notifications to mobile app and direct the user to the booking where they can confirm it or decline and add message to booking


Once booked the booking will be listed in the story under the correct group (Staff bookings, contacts, or locations)


##### Requests

For resources that are not managed by you, like cameras or helicopters, you may be able to request it for your story so someone else takes care of your request.


####### Requesting Resources


Click on the request button and you will be presented with the resource types available to request, either technical or human.

Once you select one you will be presented with the booking request method where once again you may need to fill in information about your requirements.

Note: On certain occasions sub resource types may be nested so you get to choose exactly the type of editor you need for example

Here you will notice you don´t need a calendar on the right as you are not checking someone´s particular availability but you will need to define when you need this resource for, and you could add notes or any required metadata. Again, adding a title is particularly important for clarity.


If you want to continue working on your request later, you can save it, and it will be tagged with not requested. If you have all the information ready, you can send the request to start the booking.


Sent requests will appear listed as Requested


####### Assigning Requested Resources (Managing Requests)

Users managing the allocation of time for a particular resource can configure the request left menu tray to watch for incoming requests.

Here they can filter it by

- Specific staff (people), technical (equipment), teams or guest resources

- Requests for resources in a specific office

- Requests coming from stories from a particular department

- And even just decide to view requests needed today

With the bell icon they can also subscribe to notifications for the selected filter for new incoming requests so they can be working elsewhere and be notified when a new request comes in.


The request intake tray will list out requests grouped by status

- Requested (It has been requested)

- In Progress (it has been assigned but not confirmed)

- Booked (It has been confirmed)

- Done (the booking has been marked as done)

This configuration only needs to be done once and then it is remembered in the system.


Once you have some requests to manage simply click on the arrow to reveal the booking details

This opens the request modal where you can see the details, navigate to the message thread, and have a conversation with the requester before assigning


To assign the resource click on the request card and that will display all the available resources for the requested resource type. See who is available and drag the card to the empty slot


You can then adjust the timings with the handles

Once you are happy with the timings click on the card on the right and confirm the booking

The request will now appear on the left request tray under the Booked group:


### BOOKING PAGE (AVAILABILITY)

The booking page is the perfect place to check your team´s availability.

##### View collections

It is organized like the plan or feeds pages into view collections where you can see the bookings for different teams or different resources. Each shared view has a collection of views under it.

To load a collection, go to edit - replaced with shared views, then choose the one you need to see. Your admin will have preconfigured several of these:

Be careful never to update shared views.


##### Filter

The booking page has a preconfigured filter in the middle that is based on your view. You can filter it further if necessary.


##### Date filtering and navigation

Here you can set the date you are looking at as well as set the range you are looking for. Day. week, month, or date range

The Booking Page will remember the date set when you last accessed it, so you don´t need to reset it when navigating in and out.

##### Display options

In the booking page you can choose what and how to display the information on the top right corner with the eye icon.


From metadata fields you choose to display, to the sorting behavior and much more.

Do note that when you hover over a booking card it will show all booking info, so it is not required to show it at all times.

Below the eye icon you can choose to show all resources or filter them further by their availability

- Show empty resources shows those that have no bookings assigned

- Show nonempty resources show resources with bookings on

- And show non work order bookings is the default and allows you to see bookings vs work orders


##### Adding resources to existing bookings

You can drag resources to an existing booking by dragging resources from the right resource search column to an existing card on the availability area. This is especially useful when adding equipment to people´s bookings or vice versa.

This will display it immediately below the existing booking.


### NOTIFICATIONS


Notifications are sent whenever someone confirms, asks to confirm or unconfirms a booking or when someone marks the task as done.

These notifications can be delivered via email, web browser notification or app push notification.

To setup your preferred way of receiving booking notifications go to my page - notifications

Do note that you will receive notifications for both bookings in a task and ungrouped bookings. You will not receive notifications for work orders added to your booking plan.


### GUEST BOOKINGS


####### Guest Bookings


When you want to book a guest, go to story bookings tab, choose to book either on the story or the location, select guests as the booking type:

Once you have the right selection, if you when you do a search if you do not find the right talent in the system then you can simply use the new + button next to guests on the top right


This will provide a window to create a new guest and upon completion it will land you on the correct booking page to finish the booking process.

Here you will have options to select the resource type for the guest

Enter any metadata fields from the overall human template as well as specific ones for the resource type

Add a department to limit who can see the guest

Add a location, picture, etc.

Then Proceed to the booking.

In the booking you will be pleased to know that any field in the request template that is part of the profile will not need to be filled in as it will synchronize automatically from your previous page, saving you precious time.

####### Temporary Guests

New guests can be marked as temporary to enforce a different cadence of purging (Flushing)

When you create guests, you now have an option to mark them as temporary.

This is a tag that allows you to differentiate guests you would like to keep in your database for longer from guests you are using as one off or should be cleared sooner.

In the admin resources section and navigate to the Purge Guest menu.

Here you will be able to define the rules for regular guests vs temporary guests.

The first tab will show you the rules and those resources that match the criteria

The second and third tab will show people listed under the temporary vs standard guests.

Don´t worry. No one is deleted automatically. They will just show up in the list based on your defined options so you can choose to easily flush them after the fact or keep them.


####### Guest Overview

In the guest overview you can see exactly which guests are booked for a given time range.

Who is coming into the building with clear start and end date-times.

You also have the option to display the booking note field

The view can be sorted by Start Date, Title, or End Date.

It is easy to define custom fields that you would like to display (like the studio location), which the admin can also sort as needed.

Simply add them to the request template, and “include them in search results.”

The order of the fields from the request template will be mirrored in the guest overview.


The overview can be printed to easily share it as a PDF with others for daily planning.


### MAP OVERVIEW


####### Map searches

In the map view you can search for available resources based on location.

On the right menu you can filter by what you are looking for (Crew, Guest, Equipment, Teams, Points of Interests or Stories-Productions).

With the search bar you can search for a specific location or area.

And with the zoom in buttons, you can zoom in and out to see territory.

The right column can be collapsed with the blue bottom right button.


####### Distance to location

With the map opened if you select a story from the left menu and select a resource from the map you will be able to select the show distance button which will tell you the path, distance, and time it will take that resource to get to the location by car

####### Assigning from the map

If you are happy to assign the resource based on its location, you can drag the resource card over to the story card from the left menu


####### GPS “Live” Production

Resources who make themselves available via the Wofltech Go app for Live production collaboration will show with a green indicator and if you click on them, they will be clearly displayed as available.


####### Vehicle Tracking

We have several integrations that allow you to track your production vehicles in real time in the map view (See Abax for example)

With this functionality it is easier than ever knowing where your production vehicles are to determine which one is best positioned to cover a story.

If you have a location defined, you can work out its distance and how long it will take them to drive to the required location.

If the vehicles are showing live GPS data, you will be able to see their position updating in real time for improved coordination.


### ADMIN


##### Request vs bookable resources


Resources are categorized under Resource types where you can set whether people can book this type of resources, or they should request them, so the right team takes care of the allocation.


##### Booking Permissions


You have granular permissions for bookings via new abilities that can be connected to security groups:

  - Some people should not be able to book other resources, just request them

  - Some people should be able to book resources in their own department

  - Some people should be able to book people in other departments (There will not be any restriction on what department they could book people in)


##### Resource Profile Template


You can define the type of fields you want to gather for each resource type. As much as possible our recommendation is to do this at the top level (Human, or Technical) to improve searchability


Costs can be added to resource types (for blended rates) and actual named resources

See Resourcing - Finance for more information


##### Request Template


In the resource types you can create a request template

They can also be required to make it mandatory to establish best practice when requesting resources.

You can even share some of the fields with the resource template (so the information from the profile automatically populates the request with the resource profile info for that field)


Some of these request fields can be made searchable and filterable if single or multi select and even make the field visible in the search results.


We recommend making most fields, and at least all mandatory fields to “show on main tab.” Otherwise, they will show in the Optional Info tab in the request


##### Resource Profiles


In the resource itself you can add information about the resource

Some technical resources may have workflows (Like LiveU or SonyC3p etc.)
