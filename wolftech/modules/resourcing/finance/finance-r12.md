## RESOURCING: FINANCE - COST TRACKING


####### Cost Tracking

As you begin adding resources to your production people with finance permissions can begin tracking costs against it.

At this point all of your bookings will likely not be confirmed yet but you can mark the unconfirmed checkbox to reveal all planned bookings

In this module you can:

- Add a cost budget

- Set a currency

- Set the projects rate for each resource (This may cascade from the resource type or the resource´s profile but can be overridden at the project level

- Add Projected expenses costs like travel and accommodation or hires.

- Check the delta

- Trust it is based on live bookings data

####### Budgeted Hours

In the (i) icons per resource types you will also be able to add expected number of booking hours

####### Resource Costs

Resource costs will be driven in a hierarchical order

- Resource type cost will be used as the default

- If the resource has a particular cost this will override the resource type blended rate

- A user will also be able to manually type a rate to override the resource default rate with a project specific rate

####### Planned vs Actuals

As you begin confirming bookings you can enable or disable the unconfirmed bookings check mark to see actual vs planned costs.

####### Expenses


Expenses can be added in the cost section where you can name them, add some notes and give them a cost. This is great for adding any planned or actual expenses quickly as they happen

####### Additional Info and Finance Board

Below on the board section of the finance tab you can also add sensitive documents like the actual budget or contracts knowing that only those with the finance permissions will be able to access it.

Alternatively you can host these in other secured environments and link them in the additional information section along with other crucial finance data to help you manage your project:

####### Budget codes

In many organisations, once a budget has been approved it is then activated in the finance system via a budget or finance code.


In wolftech you can add this budget code to your story or production so everyone has visibility of the reference code to use when hiring or spending against the budget.

### ADMIN

####### Permissions

In the authorisation page you can set who gets to see the finance tab as well as the cost of the resources

It is advised to create a role that includes these permissions to manage carefully the access.

####### Resource Costs

In the admin resource type you will be able to determine a cost if you want to have a blended rate for different roles so that employee costs are not visible but a rate is available to manage estimated costs


To do so add a cost at the resource type level

You can decide on the currency used

Rates can be set as

- Hourly (Per hour booked)

- Per Booking Fee (Daily booking regardless of hours on that day)


At the Resource level you can define rates again, which will override the resource type blended rate when assigning this specific resource to a job.


Here you will be able to add more options like:


- Flat Fee (Flat fee for a story or production regardless of number of days worked)

- You can also leave cost notes: comments for others doing crewing regarding rates.


All of this information will then be available in the resource profile provided that the user has finance permissions

####### Additional Information


In the Admin Custom Fields section you will be able to determine the custom fields available in the finance module

You can set multiple tabs, any kind of fields, etc.
