Recommended Nexis versions

Updated 14th May 2025

Avid Nexis client versions 2024.2, 2024.11 or later are the versions recommended to install on ALL Production Management servers

- Note: 2024.5 Nexis client and later us HTTPS API and older applications may not be able to use it properly e.g. Capture
